# Changelog

## 1.0.0 — 2026-04-28

Initial release.

- Manifest V3 Chrome extension
- Three LLM providers: Anthropic (`claude-haiku-4-5`), OpenAI (`gpt-4o-mini`), Ollama (local)
- Five tone presets: Curious, Building-on, Disagreeing, Concise, Anecdote
- Keyboard shortcut: `Ctrl+Shift+L` (`Cmd+Shift+L` on Mac)
- BYOK only — no telemetry, no operator-side servers
- Drafts comments into LinkedIn's textarea; never auto-posts
- MIT license — fork, rebrand, redistribute
