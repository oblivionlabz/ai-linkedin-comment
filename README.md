# AI Comment Drafter for LinkedIn

A Chrome extension that drafts thoughtful LinkedIn comments using your own AI provider. Source code, MIT licensed, fork-and-resell friendly.

## What it does

- Adds a small **Draft AI** button next to LinkedIn comment composers.
- Click → reads the current post text → asks your chosen LLM to draft a comment in your selected tone → inserts the draft into the textarea.
- **You always edit and click Send yourself.** Never auto-posts. ToS-clean.
- Works on the main feed and individual post pages.

## 30-second install

1. Download the source zip and unpack it.
2. Open Chrome and visit `chrome://extensions`.
3. Toggle **Developer mode** on (top-right).
4. Click **Load unpacked** and select the unpacked folder.
5. Click the extension icon, hit **Options**, configure your provider.

## Configure your AI provider

Three supported. Pick one:

### Anthropic
- Model: `claude-haiku-4-5` (fast, cheap, ~$1 per 1,000 drafts)
- Get a key: <https://console.anthropic.com/settings/keys>
- Paste it under Options → Provider → Anthropic.

### OpenAI
- Model: `gpt-4o-mini`
- Get a key: <https://platform.openai.com/api-keys>
- Paste under Options → Provider → OpenAI.

### Ollama (local, $0)
- Install Ollama: <https://ollama.com>
- Pull a small model: `ollama pull qwen2.5:3b`
- Default endpoint: `http://localhost:11434`
- Best for: developers running Ollama already, anyone wanting truly $0 cost per comment.

## Tone presets

| Preset | What it does |
|---|---|
| **Curious** | Asks one specific, non-obvious question about the post |
| **Building-on** | Adds one complementary observation that extends the idea |
| **Disagreeing** | Polite pushback with one concrete counter-example |
| **Concise** | 2-3 plainspoken sentences |
| **Anecdote** | Opens with a relevant 1-sentence personal story |

Configure default tone under **Options → Drafting defaults**.

## Keyboard shortcut

`Ctrl+Shift+L` (`Cmd+Shift+L` on Mac) — drafts a comment for the focused comment box.

Rebind under `chrome://extensions/shortcuts`.

## Privacy

- Your API key lives in `chrome.storage.local`, only on your machine.
- Drafts are generated by direct calls from your browser to your chosen provider.
- This extension has zero backend. No analytics. No telemetry. No "phone home."
- The post text you choose to draft against is sent only to your chosen provider, only when you click the button.
